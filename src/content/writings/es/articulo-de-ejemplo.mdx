Este es un artículo de ejemplo: sirve para ver cómo se maquetan los escritos del sitio y se reemplaza por el primer artículo real. Nada de lo que dice es una opinión ni un dato de Sebastian.

Este segundo párrafo existe para ver el ritmo entre párrafos: el espacio que los separa es más amplio que en los casos de estudio, para que un texto largo se lea con calma. Sus palabras solo ocupan lugar y no dicen nada sobre ningún proyecto.

## Un encabezado de sección

Cada sección de un escrito empieza con un encabezado como el de arriba y sigue con su texto. Dentro de un párrafo puede haber un enlace interno, como [la lista de trabajos](/#works), o uno externo, como [su perfil de GitHub](https://github.com/sebastianluna-dev), que se abre en otra pestaña. También puede haber una frase en **negrita** para destacar una idea.

### Un subtítulo

Un subtítulo divide la sección en partes más pequeñas. Debajo puede ir una lista con viñetas:

- Un párrafo, que es la pieza básica del texto.
- Una imagen, que va a todo el ancho de la columna.
- Un bloque de código, con su botón para copiarlo.

O una lista numerada, para pasos en orden:

1. Escribe el texto.
2. Agrega las imágenes.
3. Quita `draft` del encabezado del archivo.

<WritingFigure alt="Hueco de una imagen 16:9 de ejemplo" />

Las imágenes ocupan el ancho de la columna con proporción 16:9 y no tienen esquinas redondeadas. Mientras no hay imagen, se ve un hueco neutro como el de arriba.

| Componente | Para qué sirve                           | Cómo se escribe                                   |
| ---------- | ---------------------------------------- | ------------------------------------------------- |
| Párrafo    | Contar la idea principal                 | Texto normal, separado por una línea en blanco    |
| Imagen     | Mostrar algo que el texto no alcanza     | El componente de figura, con su texto alternativo |
| Tabla      | Comparar datos en filas y columnas       | Barras verticales y una fila de guiones           |
| Código     | Enseñar un fragmento que se puede copiar | Tres acentos graves y el nombre del lenguaje      |

La tabla de arriba tiene bordes redondeados y se desplaza de lado si no cabe. El bloque de abajo calcula el tiempo de lectura de un texto:

```ts
const words = text.trim().split(/\s+/).length;
const minutes = Math.max(1, Math.round(words / 200));
```
